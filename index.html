📦 O que é Git?

Git é um sistema de controle de versão utilizado para acompanhar alterações em arquivos e projetos, principalmente em projetos de programação.

🌐 O que é GitHub?

GitHub é uma plataforma onde podemos armazenar, compartilhar e colaborar em projetos que utilizam Git.

🚀 Por que usar?

Git e GitHub ajudam programadores a organizar projetos, acompanhar alterações e trabalhar em equipe.
